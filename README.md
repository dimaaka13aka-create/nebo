# Nebo ❄ — погода на рабочем столе Windows

Прозрачный слой поверх всех окон: снег, дождь, сакура, листопад, светлячки и звездопад.
Снег копится на окнах и панели задач и слетает, если окно дёрнуть или бросить. Клики проходят насквозь,
обои не меняются.

## ⬇ Скачать

**[Последняя версия → раздел Releases](../../releases/latest)** — скачайте файл `NeboSetup-…exe` и запустите.

- Windows 10 / 11, права администратора не нужны.
- При первом запуске Windows может показать «Windows защитила ваш компьютер» — у программы нет платной
  цифровой подписи. Нажмите **«Подробнее» → «Выполнить в любом случае»**.
- Nebo сам проверяет обновления и предлагает поставить новую версию в один клик.
- Удаление — через «Параметры → Приложения → Nebo».

## Что умеет

- **6 видов погоды:** снег, дождь с молниями, сакура, листопад, светлячки, звездопад.
- **Сугробы на окнах и панели задач.** Перетащи окно — снег сползает, брось — слетает, лишний снег
  пересыпается на окна ниже.
- **Снежки и снеговики:** катай ком курсором, таскай мышкой, ставь друг на друга — три кома оживают.
- **Снегоуборщик, Санта с подарками, Йети** и перестрелки снеговиков снежками.
- **Метель, гирлянда**, режимы «по сезону» и «как за окном» (реальная погода в вашем городе).
- Пауза в играх и полноэкранном видео, экономия заряда на батарее.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+Alt+W` | следующая погода |
| `Ctrl+Alt+P` | пауза |
| `Ctrl+Alt+N` | настройки |
| `Ctrl+Alt+S` | стряхнуть снег с окон |
| `Ctrl+Alt+D` | снегоуборщик |
| `Ctrl+Alt+G` | Санта с подарком |
| `Ctrl+Alt+Y` | Йети |
| `Ctrl+Alt+B` | метель |

## Конфиденциальность

Nebo не собирает и не отправляет личные данные. В интернет он обращается только чтобы проверить
обновления на GitHub и, если вы включили режим «Как за окном», узнать погоду в указанном городе (Open-Meteo).
